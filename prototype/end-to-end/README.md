# End-to-end MVP interaction prototype

Three variants of the complete portrait-iPhone Pedos loop, switchable via
`?variant=`, on the throwaway `/prototype/end-to-end/` route.

The question: which interaction design should be approved for recording and
managing Recordings, selecting source material, creating a curated-library or
AI-composed melody, and replaying or deleting Created Melodies?

Run from the repository root:

```sh
npm start
```

Then open:

- `http://localhost:4173/prototype/end-to-end/?variant=A`
- `http://localhost:4173/prototype/end-to-end/?variant=B`
- `http://localhost:4173/prototype/end-to-end/?variant=C`

This is throwaway UI. All data is fake and resets on reload.
