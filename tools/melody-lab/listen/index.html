The Recording shelf

Melodies with a paper trail

Each tune is a MIDI file from PDMX, a published dataset of public-domain MuseScore scores with per-score license checks. The importer keeps the top line and reports anything it drops. No note is typed in by hand.

One puff per note

Every Recording is cut to its first clean gesture: it starts at the attack, not the silence before it, and ends before any second "brrt". That is what keeps a quarter note from sounding like four sixteenths.

Closest fart for each pitch

Like a multi-sampled instrument: the engine picks a key, then gives each melody pitch its own Recording, within 3 semitones of its natural pitch, or an octave away only where the Song needs it. Each fart plays as recorded, so the tune comes through as its shape, not exact pitches. The same note always sounds the same.

Checked by ear and by machine

A pitch tracker reads every render back note by note. Each note must sound within 50 cents of its own fart, so nothing bends a fart. How close it comes to the tune is shown, not required. Recordings that can't hold a pitch on short notes are kept off them.
