# Curated Melody Fit listening pack

## Prototype question

Does deliberately distributing melody notes across multiple fart Recordings produce a more compelling result
than repeatedly transposing one best-fit Recording, and which diversity policy should become the next baseline?

Generated by `deterministic-diversity-resample-pingpong-v2` from the approved Fixture Library.
Every output is fart-only: no vocals, instruments, backing track, synthesizer, or imported performance.

`choose-individual` is the single-Recording control. `use-all` rotates through the full approved corpus
without consecutive reuse. `recommend-best-fit` selects five pitch-available Recordings and balances
their use before repeating one. Evidence records selected-versus-used coverage and consecutive reuse.

**Catalog limitation:** these melody note plans were manually encoded without authoritative source artifacts.
They are suitable for comparing renderer behavior only, not for approving provenance, rights, or release readiness.

Listening questions for each row:

1. Is the melody recognizable without reading its title?
2. Does it still unmistakably sound fart-only?
3. Are artifacts acceptable for an MVP proof?
4. Which source mode should become the implementation baseline?
