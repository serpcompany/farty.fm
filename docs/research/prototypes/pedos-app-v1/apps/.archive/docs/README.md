# Docs

This folder holds the working docs for the Pedos app.

Use it to find:

- planning docs for features, screens, and services
- research notes and implementation knowledge
- the current source-of-truth feature specs

The app is currently planned as an iPhone-first recording product with a later `Musical Fruit` / `Pedos AI` expansion.
