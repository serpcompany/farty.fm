# MIDI Data Sources

## Simple Download Sites (Popular Melodies)
- **BitMidi** — https://bitmidi.com/ — Free MIDI files, easy to browse and download
- **FreeMIDI.org** — https://freemidi.org/ — 28,000+ files across genres
- **MIDIfind.com** — https://midifind.com/ — 70,000+ MIDI files

## Curated Datasets (GitHub)
- **BiMMuDa** — https://github.com/madelinehamilton/BiMMuDa — Billboard top 5 singles from 1950-2022, manually transcribed melodies
- **POP909** — https://github.com/music-x-lab/POP909-Dataset — 909 pop songs with separated melody tracks
- **Lakh MIDI Dataset** — https://colinraffel.com/projects/lmd/ — 176,000+ MIDI files (CC-BY 4.0 license)
- **MetaMIDI Dataset** — https://github.com/jeffreyjohnens/MetaMIDIDataset — 436,631 MIDI files with artist/title/genre metadata
- **Pop-K MIDI Dataset** — https://github.com/patchbanks/Pop-K-MIDI-Dataset — 305,815 augmented pop melodies
- **ADL Piano MIDI** — https://github.com/lucasnfe/adl-piano-midi — Piano MIDI files organized by genre and artist
- **Tegridy MIDI Dataset** — https://github.com/asigalov61/Tegridy-MIDI-Dataset — MIDI dataset for Music AI models

## Public Domain / Classical (No Copyright Issues)
- **Kunstderfuge.com** — https://www.kunstderfuge.com/ — 19,300 free classical MIDI files

## Meta Resource
- **Awesome MIDI Sources** — https://github.com/albertmeronyo/awesome-midi-sources — Curated list of MIDI file sources on the web
